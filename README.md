# Ninkie's Bakes

A responsive bakery website built with React, TypeScript, Vite, and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

## Publish on GitHub Pages

1. Upload this project to a GitHub repository.
2. Make sure the default branch is named `main`.
3. In the repository settings, open **Pages** and choose **GitHub Actions** as the source.
4. Push changes to `main`.

The included workflow builds and publishes the site automatically. The build also detects the repository name so image paths and navigation work from a GitHub Pages project URL.

## Create a production build

```bash
npm run build
```
